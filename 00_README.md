# Cybersecurity Portfolio - CENFOTEC

Technical repository documenting my academic and practical journey in Cybersecurity. The content covers the design and implementation of secure IT infrastructures, security auditing, and risk governance, adhering to international standards.

---

## Areas of Competence

* **Security Operations:** Identity management, digital forensics, and incident response.
* **Infrastructure and Systems:** Server administration (Windows Server/Linux), Active Directory, and system hardening.
* **Network Security:** Zero Trust architecture, network segmentation, and traffic analysis.
* **Risk Management:** Auditing based on international frameworks (ISO/IEC 27001, CIS Controls, OWASP) and performance metrics (KPI).
