# Security Operations Foundations (CENFOTEC)

This module provides a comprehensive analysis of network infrastructure security, focusing on traffic monitoring, port diagnostics, and web application vulnerability exploitation.

---

## Lab Deliverables

### 1. Network Traffic Analysis & Port Scanning
* **Description:** This lab covers the identification of open ports and network vulnerabilities using Zenmap/Nmap. It also includes an analysis of HTTP vs. HTTPS traffic captures using Wireshark to demonstrate the importance of data encryption.
* **Key Skills:** Traffic analysis, packet sniffing, port diagnostics, encryption verification.
* **File:** [View Deliverable](./Entregable%201%20Análisis%20de%20Tráfico%20y%20Escaneo%20de%20Puertos.pdf)

### 2. Network Security Practice (Azure NSG)
* **Description:** A hands-on exercise using Azure Network Watcher to analyze network security groups (NSGs). The focus is on implementing security rules to mitigate simulated brute force attacks, DDoS attempts, and lateral movement within virtual networks.
* **Key Skills:** Cloud network security, NSG configuration, traffic flow control, threat mitigation.
* **File:** [View Deliverable](./Práctica%20Calificada%202.pdf)

### 3. Web Application Attacks (DVWA)
* **Description:** Exploitation of common web vulnerabilities using the Damn Vulnerable Web Application (DVWA). The lab demonstrates how to execute and defend against attacks like SQL Injection, XSS, and CSRF.
* **Key Skills:** OWASP Top 10, penetration testing methodology, vulnerability remediation.
* **File:** [View Deliverable](./Practica%20Calificada%203%20-%20Ataques%20en%20Aplicaciones%20Web.pdf)
